---
name: enforce-type-annotations
description: Use when defining functions to ensure clarity and maintainability.
---
1. Review all public functions and ensure they have type annotations for parameters and return values.
2. Use consistent naming conventions for types (e.g., List, Dict).
3. Document the expected types in the function docstring.
4. Run a type checker (e.g., mypy) to identify any missing or incorrect type annotations.
5. Update the codebase to include type hints for all new functions.
