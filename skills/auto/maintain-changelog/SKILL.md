---
name: maintain-changelog
description: Use when making changes to the codebase to document updates and fixes.
---
1. Open the CHANGELOG.md file before starting any modifications.
2. Create a new entry under the '## Unreleased' section for each change made.
3. Use the format '- fix(<function name>): <short description>' for each entry.
4. Ensure at least three entries are added for significant changes or bug fixes.
5. Review the changelog for clarity and completeness before finalizing changes.
