---
name: validate-file-structure
description: Use when creating or modifying files to ensure they meet required formats.
---
1. Check the file path and ensure it exists before attempting to read or write.
2. Validate the file format against the expected structure (e.g., JSON schema).
3. Ensure all required fields are present and correctly formatted.
4. Use a linter or validator tool to check for syntax errors before running the code.
5. Implement error handling to catch and log any issues during file operations.
